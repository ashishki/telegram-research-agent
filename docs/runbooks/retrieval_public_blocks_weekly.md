# Local retrieval, public proposals and weekly material inventory

Original/full-reviewed source b442682; final source/narrow PASS650b8dd. All
local package P0/P1 closed; initial STOP and narrow variants retained.
[Ledger](../verification/DAILY-package-06-D11-D12-D14-D16-20261013.md) separates
synthetic tests, matched measurements and independent findings. No live canary,
private target, production services or user acceptance is established.

Canonical retrieval uses original SQLite FTS plus at most three fixed RU/EN
lexical variants. Canonical tg:channel:message or exact t.me source URL lookup
still obeys the same source/project/date/language filters. Native cache keys
bind filters and selected snapshot. The compatibility view preserves its
existing fields; native retrieval metadata records version and variant count.
No Knowledge Atom or learned embedding prerequisite. An optional existing hashed
index is derived and must be revalidated; automatic native use remains off after
the frozen no-answer failures. Learned D46 requires a measured miss/resource
decision. Neither the vocabulary nor synthetic fixture is human search gold.

Public tools are offered only with an explicitly configured provider and bounded
selected domain policy. A planner proposal is read intent, never permission.
The current owner public formulation, separate search/fetch grants, explicit
upper bound and current job/grant state are checked before transport. Automatic private/personal/source-topic questions require a separate public
formulation; conservative gate does not promise semantic private redaction. A key alone grants no access. Discovery snippets never substitute for
fetched primary text; publication, modification and fetch times remain separate.
Unknown/stale/future publication does not establish a current fact. Live Brave
and conditional selected RSS are separate canaries, not supplied by fixtures.

Supported blocks keep exact source quotes and provenance. Facts use bounded
lexical proofs, not general semantic NLI. Derived blocks contain admitted fact
IDs and explicit uncertainty; advice has a requested goal, conditions and one
controlled proposed step. No external effect, source scope or profile mutation
comes from a block. Invalid blocks are excluded independently and reported.
v5 proof preserves numeric roles/sign typography/uncertainty and attribution;
JSON/plaintext ordinary/durable gates share it. Older v1–v4 cached proofs deny
before model replay. Numerical assertions need the full quoted numeric phrase;
non-numeric safe prefixes remain bounded. General semantic proof is unverified.

Weekly windows are [start,end): rolling168 elapsed hours or previous local
calendar week. /weekly --rolling and /weekly --calendar-week select explicitly;
the default is rolling. Source enumeration is paginated in one read snapshot,
then capped/ranked across source/channel groups before a20-item model packet.
Known omissions and unknown publication are retained; actual discovery does not
become invented publication. Ranking is local heuristic until operator evaluation.

/briefmaterials BRIEF_ID VERSION OFFSET reads a hash-bound metadata inventory,
up to20 links per page, without another model call or full archive copy. The
Brief manifest and inventory partition into bounded existing result objects,
inherit all source scopes/snapshots and share deletion lineage. Revocation,
changed selected snapshot or unavailable parent blocks access. Candidate global
cap2048 and collector payload caps are explicit; materials outside collection
are not fabricated. Host/client/retention/recovery and useful editorial quality
remain later gates. Full Chat/Search/beautiful Brief/Watch/confirmed Act retained;
Mini App excluded.
