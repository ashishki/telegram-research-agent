# PRM Operator Validation Plan

Status: proposed. It starts only after explicit operator approval; fixtures and manual runtime state are not validation evidence.

Collect 40 real questions over four weeks: 8 AI systems, 6 project application, 6 career/portfolio, 6 enterprise/product, 6 writer/editor, 4 learning, 2 reaction recall and 2 saved-memory recall. Private receipts use one interaction ID and labels initially remain unknown. Optional operator labels are usefulness, trust, wrong priority, shallow/long, irrelevant evidence, rephrase, applied, saved, decision influence, time saved and correction.

Weekly reviews separately evaluate routing, citations/retrieval, personalization, proposal safety, verification, latency/cost and operator outcomes. Privacy-safe aggregates never expose raw questions/posts. Candidate, approval-required targets are useful-or-partial >=0.80, fully useful >=0.55, citation correctness >=0.95, zero unsupported current/high-stakes claims, rephrase <=0.20, median useful time <=2 minutes, reaction searchability 1.0, confirmed write success 1.0, eight saved objects, four concrete actions, two changed decisions and an operator continuation choice.

Stop for uncited current/high-stakes claims, cross-chat/write leaks, writes before confirmation, raw-text egress/logging, migration loss or hidden freshness failure. LLM judging is advisory until calibrated against labels. Final review produces an aggregate evidence artifact and operator decision, not a release/value claim.
