# Package6 — retrieval, public discovery, supported blocks and whole-week Brief

Base d825ce5 on codex/pa-daily-implementation-20261013, clean initial tree.
[Boundary/design](DAILY-package-06-design-20261013.md). Dependencies have local
critical closure. Only isolated PG/SQLite, fake public providers and literal
loopback model/reader HTTP. No .env/personal database/session/credentials, paid
calls, production/schema/checksum changes, services/timers, external writes,
push/master integration or human acceptance. Mini App remains excluded.

D11 shares canonical retrieval across the compatibility wrapper and native
reader. Original FTS primitive is retained for matched baseline. Normalization/
three lexical RU/EN variants, canonical ID/URL lookup, post/content dedup and
channel diversity preserve scoped filters. Optional hashed candidates are
revalidated against canonical identity/hash/filter before selection; no automatic
sidecar creation or use. Cache identity now binds every filter and selected-source
snapshot. Native metadata distinguishes expanded retrieval; old API shape stays
compatible. This is lexical expansion, not learned semantic retrieval.

D12 adds a typed standalone public proposal for ordinary questions, exact
projection of current owner text, no remembered/private context, separate
discovery/fetch reservations and budget-bound fetch count. Provider/selected
domains must already be configured; no new account setup. Existing pinned DNS,
no-redirect/no-proxy/private-IP guard retained. Search snippet dates stay discovery;
fetched publication/modification/check timestamps and freshness basis are distinct.
Stale/unknown/future/conflicting public evidence cannot establish a current fact.
RSS conditional benefit not measured, connector not chosen. Live Brave untested.

D14 adds fact/inference/recommendation blocks and independent partial admission
over the actual sent evidence in durable and ordinary archive synthesis. Facts
bind exact quote/URL and ordered lexical projection, critical actors/numbers/
negation/modality plus enclosing source sentence. Cropping cannot hide those
slots. A tiny versioned RU/EN vocabulary permits a measured translation case;
unrestricted paraphrase/NLI is not proven. Derived blocks bind admitted facts;
controlled uncertain relations/advice bind requested goal and conditions, with
no effect or permission authority. Unsupported text never appears in the answer;
reject counts/conflicts stay visible. Legacy verifier remains, plaintext cannot
bypass the new durable strict gate. Arbitrary semantic inference/translation and
actual provider understanding need later evaluation, not a fabricated PASS.

D16 collects canonical pages in one bounded read transaction/snapshot before
ranked selection. Received/candidate/selected/model-omitted/document counts are
separate. Fair source/channel selection retains early high-priority material and
late small sources. Old/unknown publication can use actual discovery without
invented publication/event dates; removed content and half-open end excluded.
Global candidate cap2048 and payload cap are explicit. Rolling168h and previous
local calendar week preserve DST distinctions. Immutable metadata inventories
are partitioned below64KiB result limits and hash-bound to the Brief version;
/briefmaterials opens source links without a second model call/raw corpus copy.
Source snapshots/grants are rechecked; parent deletion cascades to inventory and
derived views. Exact period flags: /weekly --calendar-week or --rolling.
