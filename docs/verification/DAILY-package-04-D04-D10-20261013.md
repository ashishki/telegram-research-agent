## Result

Foreground intake freezes a versioned owner/bot/default-thread focus ticket.
Priority: authenticated reply, explicit result ref/quoted exact title, active
focus, compatible current response. Ambiguous/unavailable targets clarify; replay
never reselects. Topic reset preserves old result lookup. Explicit project labels
are ephemeral conversation context, not inferred durable preference/real project
objects. Short mutations share the admission/lineage fence; model I/O does not
hold focus locks. Late owner results use request context without changing newer
focus/history; completion promotes only matching generation. Parent-bound research
inherits the ticket and validates the original input/source revision before reads.
Minimal focus index survives source deletion without resurrecting deleted slots.

Optional schema planner proposes registered read/compose/preview steps with bounds,
clarification reasons and stops. It cannot grant/confirm/execute/send/delete/activate
Watch or invent a public query/project/recipient. Separate intent.plan grant and
D05 durable attempt fence; no private focus content in its packet. Unknown planning
stops automatic follow-on calls. No grant/model preserves deterministic fallback.
All proposals are revalidated and persisted; read followups bind immutable object,
version and current source permissions. Real model understanding is unverified.

SourceResource/Record/Batch/Bundle are additive to existing access carriers.
Explicit owner/resource/account/connection, observed versions, publication/event/
discovery times, actual check, completeness, continuation and known/unknown omitted
counts. Legacy collectors are bounded/unknown. Archive enumerates up to2048 items
per snapshot page before model selection; >48 items no longer imply a complete
report. Brief keeps its existing canonical20-item limit (not an increased schema),
with actual received/candidate/selected/omitted metadata and partial report status.
Round-robin selection preserves a later source. Evidence identities include scope
and snapshot; conflicts and account scopes survive merge. Exact selected identities
are required for known citation counts; ambiguous URL citations remain unknown.
Archive/web/GitHub/research/Brief and Graph mail observations share coverage facts;
source privacy comes from authorized collector scope, not source-provided labels.
No DDL/checksum rewrite or parallel policy/queue/store.
