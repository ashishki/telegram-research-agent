# Пример содержания брифа

Синтетический пример для просмотра структуры. Orion SDK и события ниже вымышлены;
модельные ответы в тесте заданы заранее. Это не новости, не живой Telegram-рендер
и не свидетельство качества реального провайдера.

**AI · 12–19 сентября**

**1. Orion SDK продолжает задачу после перезапуска**

Агент сохраняет завершённые шаги и использует их при продолжении задачи.

Сохранённый результат позволяет продолжить задачу после перезапуска.
Документация ограничивает восстановление завершёнными шагами.

**Почему выделил:** это полезный механизм для устойчивости длительных исследований.

**Можно попробовать:** если исследование прерывается, проверить восстановление
на небольшой задаче.

**Ограничение:** поведение незавершённого шага в этих фрагментах не описано.

В тесте этот пункт связан с двумя синтетическими источниками; рекламный третий
источник исключён из событий и остаётся в учёте отбора. Короткая карточка показывает
заголовок и вывод; «объясни 1» раскрывает сохранённое объяснение; «что попробовать?»
показывает предложенный следующий шаг. Во всех видах сохраняются ссылки.

Проверяемая реализация: `tests/test_assistant_brief_editorial.py`.
