## Result and boundaries

ScopedModelClient retains sealed scope groups, current guards, durable budget/
logical-task fences and one-call/no-fallback behavior. Chat Completions transport
is separate from explicit immutable capabilities: token parameter, approved
returned identities, usage semantics, streaming, store:false omission and own
client/session identity. There is no name-prefix alias or automatic model
selection. Received snapshot is recorded/priced under actual identity; missing
usage details stay unknown. Reasoning is an output subset, never added twice.
No DDL/checksum change. Speech/vision preserve their separate contracts; text
capabilities cannot silently enable those modalities.

SSE is opt-in and uses the same scoped reservation/attempt path. Bounded partial
text has no tool/confirmation authority; final acceptance requires stable model/
stream identity, stop, terminal usage and DONE. Cancellation, EOF, bad response,
unknown HTTP/redirect or accounting loss never permits another provider call.
Known 403/429 rejection and retry_after are redacted/typed without claiming zero
cost. Durable observations contain identities/digest/stop/usage/time, no prompt,
text, URL, headers or credentials. Native Telegram draft publication is D57.

Frozen 20-case manifest covers Chat, archive verification, Brief, whole ten-turn
dialogues and Watch/Act/control lifecycle. Drivers reuse genuine native fixture
composition/worker, archive synthesis/verifier, durable Brief/bindings, scheduler
and confirmed Graph effect APIs. Some source/Brief/lifecycle cases exercise
native subsystem entrypoints, not Telegram polling; no whole-product canary is
claimed. JSON traces bind source/case/manifest hashes, visible turns, immutable
object/version digests, typed outcomes/tools, actual model observations, latency,
unknown cost and forbidden effects. Public projection exports only declared
synthetic strings; other text is withheld. Recording is not provider execution.

Initial cases are dev regressions, not an independent holdout or quality score.
Full 120-unit target remains 40 Chat/30 Search/16 Brief/20 dialogues/14 lifecycle;
100 future units and real task labels/pilots remain later evaluation work. Split
checks reject source/scenario overlap across train/dev/holdout. Missing, duplicate,
changed, skipped and failed evidence cannot be replaced by keywords/success flags.
New native capture/offline verifier complements the existing strict acceptance
runner; daily runner now uses that zero-skip guard.
