table. It stores only a bounded answer summary and source references, hashes
the Telegram chat identity, expires after 30 minutes, and keeps proposal state
separate from the confirmed memory event. PRM callbacks require a chat ID;
missing, cross-chat, expired, or replayed contexts cannot create a second
memory event. Raw questions, post bodies, and internal event IDs are not shown
in callback output.
